THE ENGINE

A carry in base p, read mod q − 1

Mighty Math Magicians · Caltech Mathathon 2026

Trading p labels of class c for one of class c + 1 is exactly a carry in base p, with the top position carrying into position 0 because p to the k is 1 mod q − 1. Every admissible vector reduces to a single leaf after r = (number of labels − 1)/(p − 1) carries, each worth −1. For our digit vector the sum is m, which is 1 mod q − 1, and r = t. The picture: p = 3, k = 2, a = (3, 2): 4 trees, then 2, then 1, so 4 ≡ −2 ≡ 1 mod 3.
