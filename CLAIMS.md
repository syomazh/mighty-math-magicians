# Claim ledger

Grades: `conjecture` → `computed` → `ai-proved` → `ai-reviewed` → `human-signed`. See `CLAUDE.md`, rule 2.
Notation: p prime, q = p^k, m = (q−1)n+1 leaves, m = Σ m_j p^j in base p, s = s_p(m), t = (s−1)/(p−1).
A q-ary tree is read as a p-ary tree whose leaves all sit at depth ≡ 0 (mod k). `~` is the equivalence generated by rotating the p children of any node; d(T) = number of nodes whose p subtrees are not all equivalent.
