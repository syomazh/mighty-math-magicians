# Claim ledger

Grades: `conjecture` → `computed` → `ai-proved` → `ai-reviewed` → `human-signed`. See `CLAUDE.md`, rule 2.
Notation: p prime, q = p^k, m = (q−1)n+1 leaves, m = Σ m_j p^j in base p, s = s_p(m), t = (s−1)/(p−1).
A q-ary tree is read as a p-ary tree whose leaves all sit at depth ≡ 0 (mod k). `~` is the equivalence generated by rotating the p children of any node; d(T) = number of nodes whose p subtrees are not all equivalent.

## Known facts we rely on (from the literature, not ours)

- Konvalinka 2007, Proposition 2: the valuation formula, proved with factorial valuations.
- Konvalinka 2007, Proposition 7: every orbit of the *full* symmetry group has size divisible by p^t; his proof ends by invoking Proposition 2 for exactness.
- Deutsch–Sagan 2006: the case p = q = 2, where the number of minimal orbits is (2s−3)!! (stated from memory of the paper; **to be checked against the source**).
