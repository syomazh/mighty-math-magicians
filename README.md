**Working here with an AI agent (ChatGPT, Codex, Gemini, Cursor, Claude, ...)?** Have it read [`AGENTS.md`](AGENTS.md) first. In short: run `bash tools/guest_setup.sh <yourname>-<tool>` in your clone, work only in `guests/<yourname>-<tool>/` on the branch `guest/<yourname>-<tool>`, never push to `main`, and push your own branch when done. No fork needed.
