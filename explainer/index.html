2 · Orbit census: every class has size a power of p

A q-ary tree is read as a p-ary tree. At every node we may cyclically rotate its p children. Two trees are in the same class if a sequence of such rotations turns one into the other. If a node’s p subtrees are all equivalent, rotating there changes nothing; otherwise it produces p different trees. So a class has pd members, where d counts the asymmetric nodes.

3 · A tree and its symmetries

One q-ary node becomes a block of p-ary nodes of depth k (faint bands). Orange nodes are asymmetric, green ones symmetric. Click a node to rotate its children: at a green node the tree (as an ordered drawing) is unchanged; at an orange node you get one of the p trees of the class.

4 · Minimal trees are built from the digits of m

The smallest possible d is exactly t = (sp(m)−1)/(p−1). The classes achieving it are skeleton trees: a little p-ary skeleton whose leaves are the atoms of m — digit mj contributes mj leaves of size pj, and an atom pj hangs at depth ≡ −j (mod k).

5 · A carry is a collapsing cherry

Why is the number Nt of minimal classes never divisible by p? Give every atom a distinct label, and let T count the labelled skeletons. Cyclically permuting p labels of one class c fixes a labelled skeleton exactly when those p labels are siblings — a cherry. Counting fixed points modulo p gives T(a) ≡ −T(a − p·ec + ec+1): collapse the cherry into one atom one size up. That is precisely a carry in base p. Step through it:

the same carry in base-p columns

Each collapse multiplies the sign by −1. When only one leaf remains, every class has fewer than p labels, so no cherry is left — and after exactly t carries the sign is (−1)t. Dividing by the number of labelings, ∏ mj! (a unit mod p), the number of minimal classes is a unit mod p.
