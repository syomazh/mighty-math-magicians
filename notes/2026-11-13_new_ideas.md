# New ideas: alternative proofs and cross-field meaning

- **Date:** 2026-11-13, about 23:15 PT
- **Author:** Claude Fable 5.2 (AI). Written in response to the team's request for more elegant proofs and physical meaning.
- **Status:** ideas. Only the items marked "checked" have any evidence. Nothing is human-verified.

Notation: p prime, q = p^k, trees are p-ary and "k-blocked" (all leaves at depth ≡ 0 mod k), m leaves, m = Σ m_j p^j in base p, s = s_p(m).

- N(m) = (m − 1)/(p − 1): the number of internal nodes of any p-ary tree with m leaves.
- ν(m) = (m − s)/(p − 1) = Σ_{i≥1} ⌊m/p^i⌋: the number of internal nodes of the **digit forest** of m (m_j complete p-ary trees of height j, for each j).
- t = N(m) − ν(m) = (s − 1)/(p − 1).

## Idea 1 — The accounting proof: "every node is worth −p"

Put distinct labels 1..m on the leaves.

**L1 (labels kill all symmetry).** Every rotation class of leaf-labelled trees has exactly p^N(m) members, because with distinct labels no node is symmetric. Hence
`m! · C_n^(q) = p^N(m) · L(m)`, where L(m) is the number of leaf-labelled cyclic k-blocked trees.

**L2 (trees).** `L(m) ≡ (−1)^N(m) (mod p)`. This is the carry/cherry lemma started from m labels of class 0: cyclically permuting p labels fixes exactly the trees where they form a cherry, in p − 1 ways; collapse and repeat. Each internal node contributes one factor −1.

**L3 (the digit forest: Legendre's formula from tree symmetry).** Let 𝔉(m) be the set of digit-forest structures on {1..m}: partitions into m_j blocks of size p^j, each block arranged as the leaves of a cyclic complete p-ary tree. The symmetric group S_m acts transitively with stabilizer of order p^ν(m) · ∏ m_j!, so
`m! = p^ν(m) · ∏ m_j! · |𝔉(m)|`.
And `|𝔉(m)| ≡ (−1)^ν(m) (mod p)`, by the recursion (peel off the bottom level)
`|𝔉(m)| = binom(m, m_0) · K(m') · |𝔉(m')|`, m' = ⌊m/p⌋, where K(a) = number of permutations of pa points all of whose cycles have length p. Here binom(p·m' + m_0, m_0) ≡ 1 (rotate inside m' blocks of p points: the only fixed m_0-subset is the leftover m_0 points, as m_0 < p), and K(a) ≡ (−1)^a (cherry lemma again). Each internal node of the forest contributes one factor −1.

**Theorem.** Dividing L1 by L3: `C_n^(q) · ∏ m_j! · |𝔉(m)| = p^(N−ν) · L(m)`, with |𝔉(m)| and L(m) units mod p. So v_p(C_n^(q)) = N(m) − ν(m) = t, and in one line

> `C_n^(q) · ∏_j m_j! ≡ (−p)^t (mod p^(t+1))`.

**Checked:** the displayed congruence holds in 885 cases (p ≤ 11, k ≤ 3, n < 60), computed by Claude Fable 5.2 on 2026-11-13.

**In words.** A labelled tree has N(m) nodes and each is worth a factor −p. The m! ways of labelling can absorb only ν(m) of them, namely the nodes of the digit forest. The remaining t nodes have nowhere to go, so they appear as the power of p in the count. In the original (unlabelled) proof these t nodes are the skeleton and the digit forest is the set of atoms.

**Caveat.** This proof goes through v_p(m!), although it derives it from the same symmetry rather than quoting Legendre. Whether that satisfies "without relying on factorial valuations" is for the humans to judge. The original proof never mentions m!.

## Idea 2 — A physical statement: sand on a ring versus sand on a line

Toppling rule: **p grains on site c topple into one grain on site c+1.** (This is carrying in base p; in physics it is a chip-firing or abelian sandpile rule.)

- On the half-line 0, 1, 2, …: m grains at site 0 come to rest as the base-p digits of m, after ν(m) topplings.
- On a ring of k sites: m grains at site 0 come to rest as a single grain at site 0 exactly when m ≡ 1 (mod p^k − 1), after N(m) topplings. The quantity Σ a_c p^c mod (p^k − 1) is conserved; it should be the "sandpile group" of this ring.

> `v_p(C_n^(q)) = (topplings on the ring) − (topplings on the line)`, starting from m grains at the origin.

Equivalently, t is the number of topplings the ring still needs when it starts from the digits of m. In the proofs each toppling is a cherry collapsing, and it contributes a factor −p. The final answer does not depend on the order of topplings (abelian property), which is why the sign (−1)^t is well defined.

## Idea 3 — What the rotation classes are in other sciences (checked in the OEIS)

- **p = 3, chemistry.** The number of rotation classes of ternary trees with n nodes is 1, 1, 2, 5, 11, 28, 74, 199 for n = 1..8. The OEIS lists this as A000625: steric rooted ternary trees, the number of alkyl radicals C_nH_{2n+1} counting stereoisomers. A carbon atom's three other bonds can be rotated but not reflected, which is exactly our Z_3. Complete ternary trees are the perfectly branched molecules (dendrons). Checked against E000 output, 2026-11-13.
- **p = 2, biology.** The number of classes is 1, 1, 2, 3, 6, 11, 23, 46, 98, 207, 451: A001190, the Wedderburn–Etherington numbers, i.e. unlabelled rooted binary tree shapes, the shapes of evolutionary trees. Our d(T) counts the nodes whose two subtrees differ. Lead to verify: phylogenetics has a tree-balance index based on "symmetry nodes"; if its minimum is known to be (binary weight of the number of leaves) − 1, that is our lower bound for p = 2 found independently by biologists.
- **Lead to verify:** rooted binary trees on s labelled leaves correspond to perfect matchings on 2(s−1) points (a paper by Diaconis and Holmes on matchings and phylogenetic trees, if memory is right). The p-ary analogue would be Idea 5.

## Idea 4 — The Frobenius view (for algebraists)

Let G(x) = Σ (number of p-ary trees with m leaves) x^m, so G = x + G^p. Modulo p, G^p = G(x^p), so G ≡ x + x^p + x^(p²) + … : odd coefficients exactly at powers of p. This is the inverse of the Artin–Schreier map g ↦ g − g^p. In characteristic 0, f^p = f(x^p) + p·δ(f), where δ(f) counts non-constant necklaces of length p. Symmetric node = Frobenius x ↦ x^p; asymmetric node = p·δ. The class-counting series F(x, y) of experiment E003 is G with the number p replaced by a variable y in front of δ.

One-page proof for k = 1 by induction on m: grouping the p-tuples (m_1, …, m_p) by rotation gives c_m = [p | m]·c_(m/p)^p + p·Σ_(necklaces) ∏ c_(m_i); digit sums give the lower bound; the leading coefficients N(m) satisfy, in the ring Q[u_0, u_1, …]/(u_j^p) with u_j standing for an atom of height j and U = Σ u_j, the equation `A = U + A^p / p`. Its solution is A = Σ_t (C_t^(p) / p^t) · U^((p−1)t+1), which gives the exact count C8. Self-similarity: A = λ^(−1)·G(λU) with λ^(p−1) = 1/p.

## Idea 5 — A bijection: labelled cyclic p-ary trees ↔ permutations made of p-cycles

A cyclic p-ary tree with t internal nodes and (p−1)t+1 labelled leaves has pt non-root nodes. Label the internal nodes canonically (for instance in the order in which cherries appear when repeatedly collapsing the cherry with the smallest label). The cyclic order of the children of each internal node is then a p-cycle, and together they form a permutation of pt points with t cycles of length p. Conjecture: this is a bijection. It would explain the count (pt)!/(p^t t!) in C8 with no formula for Fuss–Catalan numbers, and for p = 2 it should be the matching correspondence of Idea 3.
