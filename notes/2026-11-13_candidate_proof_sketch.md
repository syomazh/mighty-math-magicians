# Candidate proof sketch: exact p-adic valuation of Fuss–Catalan numbers via tree symmetries

- **Date:** 2026-11-13 (first session)
- **Author:** Claude Fable 5.2 (AI). Produced while reading the problem statement, *before* anyone on the team reviewed it and *without* access to the text of Konvalinka's paper.
- **Status:** numerically checked (experiment E000, all checks pass). **Not human-verified. Novelty not checked.** Every step below needs a human sign-off before it is claimed anywhere.
- **Evidence:** `experiments/E000_first_sanity_check/check.py` and `output.txt`.

## Setting

p prime, q = p^k. `C_n^(q) = binom(qn, n) / ((q-1)n + 1)` counts q-ary trees with n internal nodes; such a tree has `m = (q-1)n + 1` leaves. Write `m = sum_j m_j p^j` in base p, `s = s_p(m) = sum_j m_j`, and `t = (s - 1)/(p - 1)`.

**Target.** `v_p(C_n^(q)) = t`, proved from tree symmetries only (no factorial valuations).

## The five steps

**Step 0 (q-ary trees are p-ary trees).** Replace each q-ary node by a complete p-ary tree of depth k. A q-ary tree becomes a p-ary tree all of whose leaves are at depth ≡ 0 (mod k), and conversely. The leaf count m is unchanged. This is why the answer depends only on m.

**Step 1 (the group and orbit sizes).** Let G be generated by the cyclic rotations (Z_p) of the p children at every p-ary node (an iterated wreath product of Z_p; on a q-ary node it induces a Sylow p-subgroup of S_q). G preserves leaf depths, so it acts on q-ary trees. Because p is prime, at each node either all p rotations give equivalent trees or all are different, so

> |orbit of T| = p^d(T), d(T) = number of *asymmetric* nodes (nodes whose p subtrees are not all G-equivalent).

**Step 2 (lower bound, d(T) ≥ t).** Induction on the tree. At a symmetric node m = p·m_1, so s_p(m) = s_p(m_1) and d(T) = p·d(T_1). At an asymmetric node d(T) = 1 + sum d(T_i) and s_p(m) ≤ sum s_p(m_i) (digit sums are subadditive; the deficit is (p−1)·#carries). Both cases give d(T) ≥ (s_p(m) − 1)/(p − 1). This is the divisibility bound.

**Step 3 (minimal orbits are "skeleton trees" on the digits of m).** Equality in Step 2 forces: a symmetric node is the root of a complete tree, and at every asymmetric node the leaf counts of the p subtrees add up *without carries*. So a minimal tree is a skeleton of asymmetric nodes whose leaves are complete p-ary trees ("atoms") of sizes p^j, with exactly m_j atoms of size p^j: the atoms are the base-p digits of m. Its orbit is the skeleton with the children of each node known only up to rotation. For q = p^k an atom p^j must hang at depth ≡ −j (mod k).

> Minimal orbits ↔ cyclic p-ary trees whose leaves are labelled by the multiset of atoms of m, atom p^j at depth ≡ −j (mod k).

For p = 2, k = 1 these are rooted binary phylogenetic trees whose taxa are the 1-bits of n+1; their number is (2s−3)!! (Deutsch–Sagan).

**Step 4 (the count of minimal orbits is a unit mod p — "a carry is a collapsing cherry").** Make the labels distinct; let `T(a)` be the number of such trees with a_c labels of class c = j mod k.

- *Forgetting distinctness is free.* The symmetric group permuting equal atoms has order prod m_j!, coprime to p, while the automorphism group of a cyclic p-ary tree is a p-group. So the action is free and `N_min = T(a) / prod_j m_j!`.
- *Carry.* Let Z_p cyclically permute p labels of the same class c. A tree is fixed iff those p labels form a cherry (p sibling leaves) in one of the p−1 compatible cyclic orders. Collapsing the cherry to one leaf one level up gives a tree with a_c − p labels of class c and one more of class c+1. Hence
  `T(a) ≡ −T(a − p·e_c + e_{c+1}) (mod p)`, indices mod k.
  This is base-p carrying, performed modulo p^k − 1 = q − 1.
- *Termination.* When every a_c < p no cherry can exist, so T = 0 unless the tree is a single leaf of class 0. Since m ≡ 1 (mod q−1), carrying ends exactly at that single leaf after t carries. So `T(a) ≡ (−1)^t (mod p)`.

**Conclusion.** `C_n^(q) = sum over orbits of p^d`, every d ≥ t, and the number of orbits with d = t is `N_min ≡ (−1)^t / prod_j m_j! ≢ 0 (mod p)`. Therefore `v_p(C_n^(q)) = t`, and as a bonus

> `C_n^(q) / p^t ≡ (−1)^t / prod_j (m_j!) (mod p)`.

For q = p there is an exact count: `N_min = (pt)! / (t! · p^t · prod_j m_j!)` (checked in E000; for p = 2 it is (2s−3)!!).

## What E000 verified (47 (q, n) cases, q ∈ {2,3,5,7,4,9,8}; 307 carry cases)

Orbit-size formula (Step 1), min d = t (Step 2), N_min equals the skeleton count (Step 3), the residue of N_min mod p and the carry recursion (Step 4). All pass.
