## Detailed findings (ordered by severity)

### F1 — Prop. 5.1 freeness proof: "fixes every node" does not follow as stated
*Location:* `paper/main.tex`, proof of Proposition 5.1, paragraph beginning "The action is free. Indeed, suppose a label permutation fixes …"
*Quoted phrase:* "It then fixes every node: at maximum depth all child pointers are fixed, and induction on decreasing depth fixes all remaining nodes."
*Severity:* Gap (expository — the conclusion is true).

*What is wrong:* From "fixes every leaf" the proof jumps to "fixes every node" by an induction whose step is not stated. A cyclic $p$-ary tree automorphism that fixes all leaves need not obviously fix internal nodes if "fixes" means pointwise — but the conclusion is true because fixing all leaves forces the tree structure to be preserved leaf-by-leaf; an automorphism of a rooted tree fixing all leaves fixes every ancestor (each node's descendant leaf set is fixed).

*How to fill it:* Replace the sentence with: "An automorphism of a rooted tree is determined by its action on leaves (each internal node is the lowest common ancestor of a set of leaves). If every leaf is fixed, every node's descendant leaf set is fixed, hence every node is fixed." Alternatively: induct from leaves upward — a node's $p$ child subtrees have disjoint leaf-label sets, so a permutation fixing all leaf labels cannot permute children.

*Why it still holds:* Labels are distinct, so the automorphism witnessing $\pi\cdot\tau=\tau$ must send each leaf to the unique leaf with the same label, hence fixes each leaf pointwise.

### F2 — Lemma 5.4 first sentence silently assumes distinct labels exclude symmetric nodes
*Location:* `paper/main.tex`, Lemma 5.4 proof, first sentence.
*Quoted phrase:* "A tree with an internal node has an internal node of maximum depth. Its $p$ children are leaves at the same depth, so all have the same class."

*What is wrong:* This shows only that among $T(\mathbf a)$ some $a_c\ge p$ would be needed. It does not address why a deepest internal node must have $p$ leaf children — if some child were itself internal, depth would not be maximal. The real justification is: take a deepest internal node; maximality forces all $p$ children to be leaves. The proof omits "by maximality" and omits that we are in the distinctly-labelled setting where (S1) is automatic.

*How to fill it:* Insert "By choice of a node of maximum depth, all $p$ children are leaves." And note this uses the definition of $T(\mathbf a)$ where $p$ distinct labels cannot all lie in one cyclic orbit unless they are exactly $p$ leaves.

### F3 — Prop. 4.3: "union of the children's multiplicities" misstates the digit argument
*Location:* `paper/main.tex`, proof of Proposition 4.3, paragraph 1.
*Quoted phrase:* "when a tree is constructed from these atoms with carry-free addition at every internal node, all atom multiplicities are uniquely prescribed: a single atom $K_j$ gives the single nonzero digit $m_j=1$, and carry-free addition gives the union of the children's multiplicities."

*What is wrong:* The phrase "union of multiplicities" is imprecise. The actual fact is: if $b^{(1)},\dots,b^{(p)}$ have base-$p$ expansions with digits $b^{(i)}_j$ and $\sum_i b^{(i)}$ is carry-free, then the digit of the sum at $j$ equals $\sum_i b^{(i)}_j$. Hence the *vector* of digits adds componentwise. The proof should say the base-$p$ digit vector of the node equals the sum of the children's digit vectors, not the "union" of multisets.

*How to fill it:* Replace with a digit-vector statement and cite Lemma 3.1 explicitly.

### F4 — Prop. 4.3: "$s_p(m)=1+(p-1)r$" needs to cite Eq. (2.1) with $q=p$
*Location:* `paper/main.tex`, end of proof of Proposition 4.3.
*Quoted phrase:* "A full $p$-ary skeleton has $\sum_jm_j=s_p(m)$ leaves, and \eqref{eq:leaves} therefore gives $s_p(m)=1+(p-1)r$. Hence $r=t(m)$."

*What is wrong:* Eq. (2.1) was stated for $q$-ary trees; here it is applied to the *skeleton* which is a $p$-ary tree considered as an unlabelled $p$-ary tree counted by its leaves. This is correct (set $q=p$), but the paper never says so. Without that note a reader may think (2.1) is being applied with the original $q=p^k$.

*How to fill it:* Add "with $q=p$" or "for $p$-ary trees".

### F5 — Lemma 2.4 (Normal form): symmetry argument abbreviated incorrectly
*Location:* `paper/main.tex`, proof of Lemma 2.4 (Normal form).
*Quoted phrase:* "The identity rotation proves reflexivity, the rotation by $-r$ proves symmetry, and addition of the two rotations proves transitivity."

*What is wrong:* $R$ is not a single rotation but a relation involving a rotation $r$ *and* subtree equivalences $T_i\sim T_i'$. Symmetry of $R$ requires: if $R(T,T')$ witnessed by $(r, T_i\sim T_i')$, then $R(T',T)$ witnessed by $(-r, T_i'\sim T_i)$. The proof mentions only the rotation by $-r$ and omits the needed symmetry of $\sim$ on subtrees (which holds by induction/coinduction on structure; $\sim$ is defined as smallest equivalence relation, hence symmetric by definition, but the argument should say so).

*How to fill it:* Add "and symmetry of $\sim$ on strictly smaller trees" or note that $R$ is proved symmetric by structural induction with the induction hypothesis that $\sim$ on subtrees is symmetric.

*Severity:* Low — the lemma is true and the fix is one clause.

### F6 — Lemma 2.5: base case and (R2) step omitted
*Location:* `paper/main.tex`, Lemma 2.5 proof.
*Quoted phrase:* "Rotating the root's $p$ subtrees only permutes subtrees whose leaves all have the same extra final depth $1$."

*What is wrong:* The proof never mentions the leaf case $\bullet\sim\bullet$, which trivially preserves the multiset $\{\}$ (empty) vs. $\{0\}$. It also does not spell out why (R2) preserves the multiset: if each $T_i\sim T_i'$ preserves depths, then $(T_i)\sim(T_i')$ does too because leaf depths are $1+\dep_{T_i}$.

*How to fill it:* Add one sentence for the leaf base case and one for (R2).

### F7 — Wrap-around carry $c=k-1\mapsto0$: depth condition under contraction is correct but not spelled out for $c=k-1$
*Location:* `paper/main.tex`, proof of Proposition 5.3, paragraph "Conversely, expanding a leaf into such a cherry raises the depth …" and Proposition 5.5 invariant.
*Quoted phrase:* "If the old leaf is at depth $r-1$, then $r-1\equiv-c-1\pmod k$, so its children satisfy $r\equiv-c\pmod k$."

*What is wrong:* Nothing — this computation is correct for every $c$, *including* $c=k-1$ where $c+1\equiv0\pmod k$. The reader may worry that expanding a class-$0$ leaf (when $k\mid c+1$) should produce class-$k-1$ leaves, not class-$0$. But the computation shows: old leaf class $c+1$ at depth $r-1\equiv-(c+1)$, new leaves class $c$ at depth $r\equiv-c$ — the residue shifts correctly. The invariant $W(\mathbf b)=\sum p^c b_c\pmod{q-1}$ is also correct at $c=k-1$ because $-p^k+1=-(q-1)$.

*Status:* No fix needed; flagged here only because the review brief asked to check this case explicitly. Verified by hand (see Hand computations).

### F8 — Prop. 5.5: $W(\mathbf b)=0$ cannot occur but is never mentioned
*Location:* `paper/main.tex`, proof of Proposition 5.5, inequality chain $0<W(\mathbf b)\le q-1$.
*Quoted phrase:* "$0<W(\mathbf b)\le(p-1)\sum_{c=0}^{k-1}p^c=p^k-1=q-1$."

*What is wrong:* The strict lower bound $W(\mathbf b)>0$ uses that the number of labels $\sum b_c$ is congruent to $1\pmod{p-1}$ (true) and $>0$ (true as long as the process hasn't deleted all labels — but carries decrease $\sum b_c$ by $p-1$ each time, starting from $s_p(m)\ge1$, ending at $1$, so never hits $0$). This chain is valid but the paper asserts $0<W$ without justification.

*How to fill it:* Add "since $\sum b_c\equiv1\pmod{p-1}$ and $\sum b_c\ge1$ throughout, $W(\mathbf b)>0$."

### F9 — Prop. 5.5 $W(\mathbf b)=q-1$ impossibility: parity argument terse
*Location:* `paper/main.tex`, sentence "Equality would require $b_c=p-1$ for every $c$, making $\sum_cb_c=k(p-1)\equiv0\pmod{p-1}$, contrary to the preceding congruence."

*What is wrong:* Nothing logically — the maximum $W=q-1$ is attained only when $b_c=p-1$ for all $c$, sum $k(p-1)\equiv0$, but the invariant says $\sum b_c\equiv1\pmod{p-1}$. So $W<q-1$. The paper's phrasing is just compressed.

*How to fill it:* Optionally expand to: "$W=q-1$ iff every $b_c=p-1$; then $\sum b_c=k(p-1)\equiv0$, contradicting $\sum b_c\equiv1$."

### F10 — Prop. 5.5 $q=2$ paragraph: termination argument needs $\sum b_c>0$ invariant
*Location:* `paper/main.tex`, paragraph "For $q=2$ we have $p=2$ and $k=1$, so a carry replaces $a_0$ by $a_0-1$."

*What is wrong:* The sentence "The terminal condition $a_0<2$ is $a_0=1$, since the number of labels remains congruent to $1\pmod{p-1}$" is correct only because $p-1=1$ makes every integer $\equiv1\pmod1$, so the congruence gives no information. What actually rules out $a_0=0$ is that $\sum b_c$ starts $\ge1$ and each carry reduces it by $1$, so it stays $\ge1$ until exactly $1$. The paper should say this.

*How to fill it:* Replace "since the number of labels remains congruent to $1\pmod{p-1}$" with "since $\sum b_c\ge1$ throughout and decreases by $1$ per carry, the only terminal value is $1$."

### Additional checks requested by the brief

**1. Well-definedness of $\sim$, normal form, constancy of $d(T)$.** $\sim$ is smallest equivalence relation containing (R1)(R2); exists. Normal form is correct modulo Finding F5. Constancy of $d(T)$ follows from Lemma 2.4: replacing a subtree by an equivalent one does not change whether the parent's $p$-tuple of classes is constant, and a rotation permutes that tuple.

**2. Class-size lemma, primality, disjointness.** Primality used exactly in Lemma 2.7 to show all $p$ rotations of a non-constant word are distinct. Disjointness: Lemma 2.4 characterises $[T]$ as $\bigcup_r \prod_i B_{i+r}$; when all $B_i$ equal the $p$ unions coincide, otherwise Lemma 2.7 gives $p$ disjoint copies — correct.

**3. Digit lemma for $r$ summands.** Proved via total power-of-$p$ term count $\sum s_p(a_i)$; not just two summands. Correct.

**4. Lower bound arithmetic.** Redone: symmetric root $m=pb$, $d=p\,d_1\ge p\,t(b)=t(pb)=t(m)$ (since $s_p(pb)=s_p(b)$). Asymmetric: $d=1+\sum d_i\ge1+(\sum s_p(m_i)-p)/(p-1)=( \sum s_p(m_i)-1)/(p-1)\ge(s_p(m)-1)/(p-1)$. Both correct.

**5. Minimal classes, depth condition, bijection, equal atoms.** Both directions proved. Depth condition $r+j\equiv0$ is $r\equiv-j$ at atom root; correct. Bijection is between *classes* (cyclic skeletons) not trees — paper states this. Equal atoms handled by making labels distinct in §5.1 and dividing by $\prod m_j!$; correct.

**6(i). Freeness of $\prod S_{m_j}$.** Conclusion true; proof gap is Finding F1. "Fixes a labelled cyclic tree" means some label permutation combined with a tree automorphism yields the same labelled tree — i.e., the permutation is realised by a tree automorphism. $p$-group claim is not needed; the paper's argument via prime-order powers of the label permutation is sufficient (any non-identity permutation has a prime-order power; if prime $\neq p$ the rotation at root must be $0$, etc.). The paper's reasoning is actually complete on this point despite Finding F1's wording issue — see Detailed findings.

**6(ii). Fixed-point count $p-1$ and class $c+1$.** Verified: $br=1$ gives $p-1$ admissible non-zero $b$, one $r$ each, $a$ quotiented by position rotation. Wrap-around $c=k-1$ correct per Finding F7.

**6(iii). $T(\mathbf a)=0$ when all $a_c<p$ and $\mathbf a\neq e_0$.** True by Lemma 5.4; gap is Finding F2.

**6(iv). Invariant mod $p^k-1$, termination, number of carries $=t$.** Verified including $q=2$ and $q=3$; gaps are Findings F8–F10, all presentational.

**7. Hand computations** — see next section. All six cases from the brief verified.

**8. Hidden factorial / Legendre / Kummer.** No proof uses $v_p(n!)$, $\binom{n}{k}$, or Kummer. The only factorial valuations are in Corollary 5.7's *exact* count, explicitly fenced off and not used for the main theorem. The residue formula's denominator $\prod m_j!$ is prime to $p$ because each $m_j<p$, proved without valuations. The reduction $\fc/p^t\equiv N_{\min}\pmod p$ uses only that non-minimal classes contribute $0\bmod p$, not any factorial.

**9. Worked examples recomputed** — see Hand computations.

**10. "Clearly" / "it follows".** No unchecked "clearly" found. Each substantive "clearly" is backed by a lemma or equation. Two places where the prose elides a one-line check are Findings F2 and F8.

### Paper's worked examples (recomputed)

**Ex. 6.1 — Binary $(2,1,6)$.** $C_6=132$, $m=7=111_2$, $s_2=3$, $t=2$. Atoms $K_0(1),K_1(2),K_2(4)$ leaves. $132/4=33\equiv1\equiv(-1)^2/(1!1!1!)$. Corollary gives $4!/(2!\,4\cdot1)=24/8=3$ minimal classes — the three rooted binary trees on 3 labels: $((1,2),4),((1,4),2),((2,4),1)$. Matches paper.

**Ex. 6.2 — Ternary $(3,1,8)$.** $C^{(3)}_8=43263$, $m=17=122_3$, $s_3=5$, $t=2$. Atoms: $1\times9,2\times3,2\times1$. $43263/9=4807$, $4807\equiv1\pmod3$. Residue: $(-1)^2/(2!2!1!)=1/4\equiv1\pmod3$ (since $4\equiv1$). $N_{\min}=6!/(2!\,9\,2!\,2!)=720/72=10$ — paper's arithmetic uses $6!/(2!\cdot3^2\cdot2!\,2!\,1!)$ same value. Labelling: $T(5)=40$, $40/4=10$.

**Ex. 6.3 — Quaternary $(2,2,4)$.** $C^{(4)}_4=140$, $m=13=1101_2$, $s_2=3$, $t=2$. Atoms heights $0,2,3$ → classes $0,0,1$ → $\mathbf a=(2,1)$. Only binary skeleton with two nodes has one leaf at depth 1 (must be class 1, i.e. $K_3$) and two at depth 2 (classes 0, i.e. $K_0,K_2$). So exactly one minimal class, as claimed. Carries $(2,1)\to(0,2)\to(1,0)$ two steps, $T=1$.
