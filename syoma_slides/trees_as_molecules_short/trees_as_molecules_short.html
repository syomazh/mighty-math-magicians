A ternary tree is a drawing of an alcohol

IN THE PROOF · DEFINITION

“A p-ary tree is either a leaf or an ordered p-tuple (T₁,…,T_p) of p-ary trees, attached from left to right to a new root.”

Root, 2 nodes, 5 leaves. In general n nodes carry 2n + 1 leaves.

IN CHEMISTRY · ETHANOL

Carbon has 4 bonds: one up, 3 down, each to a carbon (node) or a hydrogen (leaf). So CₙH₂ₙ₊₁OH has 2n + 1 leaves.

orange = OH (root)

gray = carbon (node)

blue = hydrogen (leaf)

Quote: paper/main.tex, the definition of a p-ary tree. With p = 3, alcohols C_nH_(2n+1)OH and plane ternary trees with n nodes are the same shapes, once the order of the three down-bonds is fixed. The leaves are the hydrogens on carbon; the H of OH is not counted. So s₃(2n + 1) in the theorem is the base-3 digit sum of that number.

A rotation class is one molecule

IN THE PROOF · ROTATION CLASSES

“Two trees in one class are called rotation equivalent; [T] denotes the class of T.”

A rotation turns the three children of one node cyclically, anywhere in the tree.

C₂⁽³⁾ = 3 plane trees, and they form one class [T].

IN CHEMISTRY · FREE ROTATION

A carbon’s three groups spin freely about the bond toward the root: the same molecule.

Plane trees are drawings; rotation classes are the molecules (mirror forms apart).

Class counts 1, 1, 2, 5, 11, 28, … are the stereoisomer counts of alcohols (OEIS A000625; Blair–Henze 1932), checked to 14 carbons.

The three trees on the left are all ethanol, CH₃–CH₂–OH. Quote: the definition of rotation equivalence in the report; (R1) rotate the children of one node, (R2) do it anywhere inside the tree. The chemists’ model with free rotation about every C–C bond is Robinson, Harary and Balaban (1976), read by AI. Class counts: guest experiment EC01, checks A1 to A2, compared with OEIS A000625.

IN CHEMISTRY · DRAWINGS PER MOLECULE

tert-butanol: no amber carbon, d = 0, 1 drawing

butan-1-ol: 3 amber CH₂’s, d = 3, 27 drawings

Lopsided (amber) = asymmetric node. A chemist’s “asymmetric carbon” is narrower: three different groups only.

d(T) = number of asymmetric nodes; it is the same for every tree in a class, so d belongs to the molecule. At a symmetric node a rotation changes nothing (factor 1); at an asymmetric node it gives 3 different trees (factor 3). tert-butanol is the complete tree K_2. Vocabulary: three different groups = a stereocentre; C, H, H = a prochirality centre (IUPAC glossary read through a summarising tool; not checked by a chemist). Do not say “asymmetric carbon” for the CH₂ kind.

Why 55 is not divisible by 3

IN THE PROOF · THEOREM 1 AND ITS PROOF

“If p is prime, k ≥ 1, q = p^k, n ≥ 1, and m = (q − 1)n + 1, then v_p(C_n^(q)) = (s_p(m) − 1)/(p − 1) =: t.”

Every class has size 3ᵈ with d ≥ t, and the number of classes with d = t is prime to 3. So v₃ = t: the fewest lopsided carbons set the power of 3.

n = 4, q = 3: m = 9 = 100₃, so t = 0 and 3 ∤ C₄⁽³⁾ = 55.
