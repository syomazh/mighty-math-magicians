A rotation class is one molecule

IN THE PROOF · DEFINITION

“Two trees in one class are called rotation equivalent; [T] denotes the class of T.”

C₂⁽³⁾ = 3 plane trees, and they form one class [T].

IN CHEMISTRY · ONE STEREOISOMER

A chemist writes all three drawings the same way, because the molecule spins between them by itself:

CH₃–CH₂–OH

So plane trees are flat drawings, and rotation classes are the molecules themselves (stereoisomers: left- and right-handed forms count as different).

Our class counts for n = 1…8 are 1, 1, 2, 5, 11, 28, 74, 199: the stereoisomer counts of alcohols (OEIS A000625; Blair and Henze 1932). Checked by script up to 14 carbons.
