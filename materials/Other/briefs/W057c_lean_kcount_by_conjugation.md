## What this is

Appendix C of `report/report.tex` (source `paper/accounting_proof.tex`), proof of Lemma L4, second claim. For a prime p let K(a) be the number of permutations of p·a points all of whose cycles have length p. Claim: K(a + 1) ≡ (p − 1)·K(a) modulo p, hence K(a) ≡ (−1)^a.

The text's argument: fix a p-cycle c on p of the p·(a + 1) points. The group of order p generated by c acts on these permutations by conjugation. A permutation π fixed by the action commutes with c, so it maps the p points of c to themselves, and on them it is a power c^u; it has no fixed point, so u ≠ 0 (p − 1 choices, each a single p-cycle because p is prime); on the other p·a points it is any permutation with all cycles of length p. So the number of fixed permutations is (p − 1)·K(a), and the number of all is congruent to it modulo p.

Lean already has the congruence by Wilson's theorem (another worker derives `Kcount p a = W p a` from `lean/MMM/Dwork.lean`). **Only the conjugation proof is wanted here.** Do not deliver a proof by Wilson's theorem or by the formula K(a)·a!·p^a = (p·a)!.

4. Fixed points: π with `c * π = π * c`. Then π maps `Sum.inl` points to `Sum.inl` points (the support of c is the set of `inl` points, and a permutation commuting with c keeps its support: grep `Commute` with `support` in `Perm/Support.lean`, or directly: `c (π x) = π (c x) ≠ π x` when `c x ≠ x`). On the `inl` part π commutes with `x ↦ x + 1`, so it is `x ↦ x + u` with `u = π 0`. Since the cycle type has sum `p * (a + 1)` = the number of points, π has no fixed point, so `u ≠ 0`. Translation by `u ≠ 0` on `ZMod p` has cycle type `{p}` (order p, no fixed point). So π is `Equiv.sumCongr (Equiv.addRight u) π₂` and the cycle type of π is `{p} + cycleType π₂` (the two parts are disjoint permutations), so `π₂` has cycle type `replicate a p`. This gives a bijection between the fixed points and `{u : ZMod p // u ≠ 0} × {π₂ : Equiv.Perm (Fin (p * a)) // π₂.cycleType = Multiset.replicate a p}`, whose number is `(p - 1) * Kcount p a`.
5. The last theorem: induction on a; `Kcount p 0 = 1` (the only permutation of `Fin 0`, with empty cycle type); cast the step into `ZMod p`, where `((p - 1 : ℕ) : ZMod p) = -1`.
