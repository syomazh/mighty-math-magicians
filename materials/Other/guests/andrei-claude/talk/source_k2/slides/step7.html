STEP 7

The cherry collapse

Choose any p labels x₁, …, xₚ of the same class c, and let σ move these labels in a p-cycle x₁ → x₂ → ⋯ → xₚ → x₁, fixing all other labels. Every orbit has 1 or p trees, so |T(a)| ≡ |Fix(σ)| (mod p), where Fix(σ) = {trees fixed by σ}.

k = 2, a = (6, 1): the x and y have class 0 (depth 2), u has class 1 (depth 1). With σ = (x₁ x₂ x₃), 72 of the 80 trees move, in 24 orbits of size 3. (In T(3, 2), the example of Step 6, all 4 trees are fixed.)

Now a Z_p action on the lifted set. Pick any p labels of the same class, it does not matter which, and move them in a p-cycle, leaving the other labels alone. The depth condition only sees classes, so this maps T(a) to itself. Orbits have size 1 or p, so mod p only fixed trees count. In the example of Step 6, T(3, 2), the three class-0 labels always form a cherry, so every tree is fixed and there is nothing to draw. The picture is the next case up for k = 2, a = (6, 1): six labels of class 0 at depth 2 and one of class 1 at depth 1; 80 trees, of which 72 are in orbits of three like this one and 8 are fixed.
