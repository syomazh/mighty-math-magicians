STEP 6

Make the labels distinct

Give the atoms distinct names; a label’s class is its height mod k. T(a) is the set of trees with these labels, children taken up to cyclic rotation at every node, a label of class i at depth ≡ −i (mod k).

Permuting equal-height labels is a free action: its order is prime to p, while symmetries of a cyclic tree have p-power order. Every digit is below p, so ∏ mⱼ! is prime to p. It remains to show p ∤ |T(a)|.

q = 3, n = 8: |T(5)| = 40 = 2!·2!·1!·10.

Here is the lift. Repeated labels make S(m,k) awkward to count mod p, so we make them distinct. That multiplies the count by the product of the digit factorials, which is harmless because each digit is less than p. The lifted set only remembers each label’s class, its height mod k, and that leaves room for a p-cycle.
