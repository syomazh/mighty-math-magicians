STEP 7

The cherry collapse

Choose any p labels x₁, …, xₚ of the same class c, and let σ move these labels in a p-cycle x₁ → x₂ → ⋯ → xₚ → x₁, fixing all other labels. Every orbit has 1 or p trees, so |T(a)| ≡ |Fix(σ)| (mod p), where Fix(σ) = {trees fixed by σ}.

q = 3, n = 8, a = (5), σ = (x₁ x₂ x₃): 36 of the 40 trees move, in 12 orbits of size 3.

Now a Z_p action on the lifted set. Pick any p labels of the same class, it does not matter which, and move them in a p-cycle, leaving the other labels alone. The depth condition only sees classes, so this maps T(a) to itself. Orbits have size 1 or p, so mod p only fixed trees count. In our example, 36 of the 40 trees are in orbits of three like this one.
