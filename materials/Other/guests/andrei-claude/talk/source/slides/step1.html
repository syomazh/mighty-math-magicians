STEP 1

A q-ary tree is a p-ary tree

Each q-ary node becomes a complete p-ary tree of height k.

q = 4, p = 2, k = 2, n = 3: all m = 10 leaves sit at depth 2 or 4. Conversely, cutting at depths 0, k, 2k, … recovers the q-ary tree.

Mighty Math Magicians · Caltech Mathathon 2026

Replace every q-ary node by a complete p-ary tree of height k whose q bottom slots receive the branches in order. This is a bijection onto p-ary trees with m leaves, all at depth divisible by k. From now on, q only survives as this depth condition.
