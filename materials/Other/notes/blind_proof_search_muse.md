# Three Independent Strategies for the Exact p-Adic Valuation

**Theorem.** For p prime, k ≥ 1, q = p^k, let C_n^{(q)} = binom(qn,n)/((q-1)n+1) count q-ary trees with n internal nodes. Write m = (q-1)n+1. Then v_p(C_n^{(q)}) = (s_p(m) − 1)/(p−1), where s_p(m) is the sum of the base-p digits of m.

**Scope.** All lemmas are stated precisely; proofs are given or marked GAP. Computational verification for each strategy is in `experiments/E008_blind_muse/` (run `uv run python experiments/E008_blind_muse/check_all.py` and `check_extra.py`). No use is made of Legendre's formula, factorial valuations, or binomial-valuation identities beyond what is re-derived combinatorially. For the purpose of this report "not using the valuation of factorials/binomials" means: every appeal to v_p(binom(a,b)) is either (a) proved below from base-p combinatorics of digits, not from v_p(n!) = …, or (b) flagged as GAP.

## Strategy A — Orbit Counting: A p-Group Acting on q-Ary Trees

### Key idea (≤ 5 lines)

Picture an infinite q-ary tree T_∞^q: every node has q ordered children. The finite subgroup H of automorphisms that permute consecutive p-blocks of children at each node is a p-group. It acts on the set X_{n,q} of q-ary trees with n nodes (embedded as subtrees of T_∞^q). Orbit–stabiliser + Cauchy tells us v_p(|X_{n,q}|) ≥ min_O v_p(|O|). We characterise the minimal orbit exponent combinatorially and show it equals (s_p(m)−1)/(p−1).

### Setup

*Definitions.* A q-ary tree with n nodes is a finite rooted subtree of T_∞^q containing the root, in which each node has q "slots" (some may be empty). Equivalently it is the usual combinatorial object: a rooted plane tree where each internal node has q ordered children, each independently empty or a q-ary subtree. The count is C_n^{(q)}. Let X = X_{n,q} denote the set of such trees.

Fix p prime, q = p^k. View q = p·p^{k−1}. Partition the q children of each internal node of T_∞^q into p consecutive blocks of size p^{k−1}. Concretely label children 0,…,q−1; block j = { j·p^{k−1}, …, (j+1)·p^{k−1}−1 } for j = 0,…,p−1.

Let g at depth d be the permutation of T_∞^q that cyclically rotates the p blocks at a single chosen node v (keeping the internal structure within each block intact) and fixes everything else. The group H_n^q generated by all such g for nodes v of depth < n is a finite p-group. (It is iterated wreath product C_p ≀ … ≀ C_p; its order is p^{(q^n−1)/(q−1)}.) It acts on X by permuting which block each subtree falls into.

### Lemmas

**Lemma A1 (Orbit size is a p-power; description).** Every H_n^q-orbit on X has size a power of p. More precisely, if T ∈ X and O = H_n^q · T, then

    |O| = ∏_{v : v is a white node of T}  p / gcd(p, m_1(v), …, m_p(v))  times a product of multinomial factors

where at each "white" node v the p blocks carry multisets of subtree-isomorphism types with multiplicities m_1(v),…,m_p(v). In particular |O| is a p-power.

More concretely for the cyclic-block action as defined above, |Stab(T)| is computed level by level: at each node v, the cyclic group C_p fixes v iff the p blocks below v are pairwise isomorphic as (labelled) forests. If they are not all isomorphic, the orbit contributes a factor p at v. Thus v_p(|O|) equals the number of nodes v of T where the p blocks are not all identical, counted with recursive multiplicity.

*Proof.* H_n^q is a p-group, so orbit sizes divide |H_n^q|, hence are p-powers. The stabiliser description follows from the wreath-product structure: an element fixing T must fix at each node the partition of blocks into isomorphism types. ∎

**Lemma A2 (Orbits partition; valuation lower bound).** |X| = Σ_O |O| where the sum is over orbits. Hence C_n^{(q)} = Σ_O |O|, and v_p(C_n^{(q)}) ≥ min_O v_p(|O|). Moreover if all orbits of minimal valuation have the same residue mod p after dividing by p^{min}, the valuation is exact.

*Proof.* Standard orbit decomposition. For the inequality: v_p(Σ_O |O|) ≥ min v_p(|O|), with equality iff Σ_{O : v_p(|O|)=min} |O|/p^{min} is not ≡ 0 (mod p). ∎

**Lemma A3 (Minimal valuation = digit sum).** min_O v_p(|O|) = (s_p(m) − 1)/(p−1), where m = (q−1)n+1.

*Proof attempt / GAP.* The white/black vocabulary: call a node of T_∞^q black (with respect to T) if all q children of T at that node are isomorphic (empty slots count); otherwise white. For T ∈ X, white nodes contribute at least one factor p to |O|; chains of repeated white patterns can force extra factors. The minimal-orbit trees are those that are as symmetric as possible, i.e. built by recursively "p-ifying" a balanced skeleton.

Concretely, write m in base p: m = Σ d_j p^j, Σ d_j = s_p(m). Think of m as the number of leaves (or "boundary slots") of a q-ary tree with n internal nodes — check: for q-ary trees, leaves = (q−1)n+1 = m. So m counts leaves. Expanding a leaf into an internal node replaces 1 leaf by q leaves (net gain q−1 = p^k − 1 leaves). Growing a tree from the trivial tree (1 leaf) to n internal nodes amounts to n expansions, tracking leaves mod p-powers.

A tree achieving minimal orbit valuation is one where at each white node the p blocks differ in the most economical way allowed by the leaf count. Induction on n: let n₀ = ⌊n/p⌋ or similar p-adic truncation. The orbit exponent decomposes as 1 + sum of exponents of subtrees in a way that mirrors the digit sum recursion s_p(m) = d₀ + s_p((m−d₀)/p).

GAP: The full induction that links the combinatorial optimum over trees to the digit-sum recursion is not completed here. The difficulty is to prove *both* ≤ and ≥: that no tree forces fewer carries than the digit sum predicts, and that some tree achieves it. The ≥ direction was proved by Konvalinka (Prop. 7) for divisibility; the = requires also exhibiting a residue argument (see Lemma A4). For q = p = 2 the exhaustive enumeration below confirms the formula for n ≤ 6 (and random checks to n = 20), but a general combinatorial proof of Lemma A3 independent of Kummer/Legendre is the remaining gap.

**Lemma A4 (Residue; exactness).** Let ξ = (s_p(m)−1)/(p−1). Then Σ_{O : |O|=p^ξ} |O|/p^ξ ≡ 1 (mod p). In particular the coefficient of p^ξ in |X| is nonzero mod p, so v_p(|X|) = ξ exactly.

GAP: Konvalinka proves divisibility (all orbits contribute ≥ p^ξ) without the exactness. To get equality one must count minimal orbits modulo p. For q = p prime, conjecturally there is a p-to-1 map from minimal orbits to something prime-to-p, or a direct count showing the number of minimal orbits is ≡ 1 (mod p). No complete combinatorial argument for this residue is supplied here; see Strategy B for a generating-function alternative that is more promising for exactness.

This is essentially Konvalinka's line; the new content would be a *purely tree-combinatorial* proof of A3–A4, which is not delivered here.

## Strategy B — The Functional Equation G = x + G^q Read Modulo p^t

### Key idea (≤ 5 lines)

Let G(x) = Σ_{n≥0} C_n^{(q)} x^{(q−1)n+1} (with C_0=1) — the generating function of q-ary trees, characterised by G = x + G^q. Reduce coefficients modulo p. Over 𝔽_p the Frobenius (a+b)^p = a^p+b^p makes G mod p *sparse*: only powers of p appear, each coefficient 1. Lift to mod p^2, p^3,…: each lift allows only exponents whose digit-sum is bounded, and v_p of the coefficient of x^m is forced to be (s_p(m)−1)/(p−1). No factorial appears.

### Setup

Formal power series in ℤ_{(p)}⟦x⟧. Define

    G(x) = Σ_{n≥0} C_n^{(q)} x^{(q−1)n+1}   ∈ ℤ⟦x⟧,   C_0^{(q)} = 1,  C_n^{(q)} for n≥1 as usual.

Enumeratively, G counts q-ary trees by number of leaves (or equivalently internal nodes): the standard decomposition — a q-ary tree is either a single leaf (contributes x) or a root with q subtrees (contributes G^q) — gives:

**Proposition (Functional equation).** G = x + G^q in ℤ⟦x⟧.

*Proof.* Conditioning on whether the root is a leaf or internal; classical. Verified computationally for q=2,3,4 to degree 75 in `check_all.py` and `check_extra.py` (G vs x+G^q agree). ∎

Write G_t = G mod p^t (coefficients reduced mod p^t). Write v_p(a) for the p-adic valuation of a coefficient.

### Lemmas

**Lemma B1 (Sparsity mod p).** Let q = p^k. Then in 𝔽_p⟦x⟧,

    G mod p = Σ_{j≥0} x^{p^j}.

Equivalently, C_n^{(q)} ≢ 0 (mod p) iff m = (q−1)n+1 is a power of p, and then C_n^{(q)} ≡ 1 (mod p).

*Proof.* Work in 𝔽_p⟦x⟧. By Freshman's dream, for any series H, H^q = H^{p^k} = (H^p)^{p^{k−1}} and H^p = Σ a_i^p x^{pi} if H = Σ a_i x^i (Frobenius on coefficients and exponents). Since G = x + G^q, reducing mod p gives G = x + G^{p^k} in 𝔽_p⟦x⟧.

We solve G = x + G^{p^k} in 𝔽_p⟦x⟧ by iteration: define G^{(0)} = x, G^{(t+1)} = x + (G^{(t)})^{p^k}. Because v_x(G^{(t)}) → ∞ off any fixed degree, the limit G = lim G^{(t)} exists and satisfies the equation uniquely (standard formal implicit function theorem, as ∂/∂G (G − G^{p^k} − x)|_{G=0} = 1 ≠ 0).

Compute the limit: G^{(1)} = x + x^{p^k}. In 𝔽_p, (x + x^{p^k})^{p^k} = x^{p^k} + x^{p^{2k}}. So G^{(2)} = x + x^{p^k} + x^{p^{2k}}. Inductively G^{(t)} = x + x^{p^k} + x^{p^{2k}} + … + x^{p^{tk}}. Hence G = Σ_{j≥0} x^{p^{jk}}.

Wait — this gives powers p^{jk}, not all p^j. Which is correct depends on q. For q = p (k=1) we get Σ x^{p^j} ✓. For q = p^k with k>1, the mod-p support is { p^{jk} : j≥0 }, i.e. every kth power of p. But our computational check in `check_extra.py` shows for q=4=2^2, nonzero C_n mod 2 occur at m = 1,4,16,… = powers of 4 = 2^{2j} — exactly p^{jk}. For q=9=3^2, at m=1,9,81,… = 3^{2j}. So indeed the correct statement is:

    G mod p has support { p^{jk} : j ≥ 0 }, coefficient 1.

And C_n^{(q)} mod p ≠ 0 iff m = (q−1)n+1 = p^{jk} for some j — equivalently m is a power of p (since if m = p^t then t must be divisible by k for m ≡ 1 mod (p^k−1)). Let's verify: m ≡ 1 mod (q−1) = p^k−1. Powers p^t ≡ 1 mod (p^k−1) iff k | t. So the condition "m is a power of p" is correct, and it automatically forces the exponent to be a multiple of k. Checked computationally for all p,k up to 5,2 and n≤39: no mismatches (`check_extra.py`).

Thus Lemma B1 is proved for all q = p^k. ∎

*Remark.* The key tool is Frobenius, not factorial valuations. The iteration captures the intuition: mod p, raising to the pth power just stretches exponents by p, so the equation G = x + G^{p^k} can only be satisfied by a sparse series.

**Lemma B2 (Lifting: valuation from sparsity).** For each t ≥ 1, write G mod p^t. The valuation of the coefficient of x^m in G is at least (s_p(m)−1)/(p−1) minus an error that vanishes after accounting for the p-adic carry structure. More precisely:

Let m = (q−1)n+1. Expand G = Σ c_m x^m. Then v_p(c_m) = (s_p(m)−1)/(p−1).

GAP — proof sketch for the induction step: From G = x + G^q, extract the coefficient of x^m:

    c_m = [x^m] G^q = Σ_{m_1+…+m_q = m} c_{m_1} … c_{m_q}

with the convention c_1 = 1 and c_m = 0 unless m ≡ 1 mod (q−1). This is a convolution recurrence. Assume inductively that v_p(c_{m_i}) = (s_p(m_i)−1)/(p−1) for m_i < m. Then each summand has valuation Σ (s_p(m_i)−1)/(p−1) = (Σ s_p(m_i) − q)/(p−1). We need to show the minimum over compositions m_1+…+m_q = m of Σ s_p(m_i) is s_p(m) + (q−1)·(number of carries), which is ≥ s_p(m) + (q−1), with equality achieved by the "no-carry" split. Subtracting the q and accounting for the fact that we are looking at v_p(c_m) itself (not the summand) yields v_p(c_m) = (s_p(m)−1)/(p−1).

The step "minimum of Σ s_p(m_i) over compositions m_1+…+m_q = m relates to carries" is a purely base-p digit observation:

*Carry lemma (used here, proved below in Strategy C without Legendre):* For any composition m = Σ m_i, Σ s_p(m_i) = s_p(m) + (p−1)·carries_p(m_1,…,m_q), where carries_p counts total p-adic carries when adding m_1,…,m_q in base p. This follows from s_p(a)+s_p(b) = s_p(a+b)+(p−1)·carries_p(a,b), which is elementary (each carry reduces digit sum by p−1).

So the valuation of each summand is (s_p(m)−1)/(p−1) + carries_p(m_1,…,m_q). The leading term(s) are those with zero carries (possible iff no digit of the m_i sums to ≥ p). The sum of zero-carry contributions is prime-to-p (it counts compositions without carry, a binomial-type count), while all other terms are divisible by higher powers of p. Hence v_p(c_m) is exactly the minimal valuation among summands, which is (s_p(m)−1)/(p−1).

GAP: The claim that the zero-carry contribution is not 0 mod p needs justification. For q = p this is tractable (the number of ways to split base-p digits without carry is a product of binomial coefficients, each prime-to-p by Lucas — but invoking Lucas here is not factorial-based; it is the statement that binom(a,b) mod p ≠ 0 when b's digits ≤ a's digits, which has a direct combinatorial proof via lattice paths). For general q = p^k the combinatorics of zero-carry compositions is more involved and not fully worked out here.

**Corollary (Theorem).** Under Lemma B2, v_p(C_n^{(q)}) = (s_p(m)−1)/(p−1) where m=(q−1)n+1, since C_n^{(q)} = c_m.

*Computational check.* `check_all.py` verifies the valuation formula for all p ≤ 5, k ≤ 3, n ≤ 20 (and spot checks to n=39 in `check_extra.py`), all pass. `check_extra.py` also verifies B1's prediction: nonzero mod p exactly at m = p-power, coefficient 1.

**Self-assessment:** Complete modulo GAPs. Lemma B1 is fully proved (Frobenius iteration). Lemma B2's *structure* — reduction to a carry-counting optimisation + residue claim — is sound and matches observed data, but the residue non-vanishing (zero-carry sum ≢ 0 mod p) is flagged GAP for general k. For q = p (k=1) the gap is fillable with a short Lucas-type argument that itself is factorial-free (see references in Strategy C). So: heuristic-complete in general; complete modulo an elementary binomial-mod-p lemma for q=p.

**What a first-year student would find hardest:** Why (a+b)^p = a^p+b^p mod p extends to power series (Freshman's dream) and why that forces sparsity; the step from "G satisfies G = x+G^q" to extracting a recurrence for coefficients.

## Strategy C — Cycle Lemma, Necklaces, and Carries

### Key idea (≤ 5 lines)

The cycle lemma gives C_n^{(q)} = binom(qn, n)/((q−1)n+1): among all binom(qn,n) words with n marked spots, rotate each necklace so the ballot condition picks exactly one representative. So v_p(C) = v_p(binomial) − v_p(m). Counting carries when adding n + (q−1)n in base p makes digit sums appear, and the necklace picture explains why we divide by m.

### Setup

Write m = (q−1)n+1. The cycle lemma (Dvoretsky–Motzkin, Raney) states: the number of Łukasiewicz words / plane forests / polygon dissections counted by C_n^{(q)} equals (1/m)·binom(qn, n). Concretely, consider words of length qn over {0,1} with n ones; under cyclic rotation they fall into necklaces of size dividing qn; exactly one rotation per necklace satisfies the ballot/Lukasiewicz condition, and the count is binom(qn,n)/m. Integrality of the division is part of the lemma (proved bijectively, no arithmetic needed).

Hence as integers: C_n^{(q)} · m = binom(qn, n). Therefore

    v_p(C_n^{(q)}) = v_p(binom(qn, n)) − v_p(m).        (†)

We now evaluate v_p(binomial) purely via base-p carries (Kummer's theorem), but we *prove* Kummer combinatorially rather than via factorials.

### Lemmas

**Lemma C1 (Combinatorial Kummer — no factorials).** Let a ≥ b ≥ 0. Let carries_p(a,b) be the number of carries when adding b and a−b in base p (equivalently, the number of positions where b_i > a_i after accounting for incoming carry). Then

    v_p( binom(a,b) ) = carries_p(a,b) = (s_p(b) + s_p(a−b) − s_p(a))/(p−1).

*Proof (factorial-free).* Count binom(a,b) as the number of b-subsets of an a-set. Partition the a-set into p blocks as evenly as possible and induct on a. Alternatively, the standard generating-function proof: (1+x)^a = ∏_j (1 + x^{p^j})^{a_j} · (1 + x^{p^j +1})… is messy. Simpler: we prove the digit-sum identity first, then identify v_p with carries.

The digit-sum identity s_p(u)+s_p(v) = s_p(u+v) + (p−1)·carries_p(u,v) is elementary: adding u and v in base p, each carry replaces p in one digit by 1 in the next, changing the sum by −(p−1). Summing over carries gives the formula.

To connect to valuations: binom(a,b) = (a·…·(a−b+1))/b! — but we avoid factorials. Instead we use the base-p expansion of the binomial coefficient via Lucas-type recursion. Define f_p(a,b) = binom(a,b) mod p^t inductively via Granville/A. The exponent of p dividing binom(a,b) equals the number of carries, proved by induction on a: write a = pA + a₀, b = pb₀? Deferring the full induction—

GAP: A fully self-contained factorial-free proof of Kummer's theorem is standard but not reproduced here in full. It can be done via the combinatorial interpretation of carries (see e.g. the "base-p addition" proof in Graham–Knuth–Patashnik §4.2, or via the group-action proof that binom(pa,pb) ≡ binom(a,b) mod p^2). We take Lemma C1 as *known with elementary proof* — i.e. we claim it is provable without Legendre, and we have verified it computationally for all a≤100, p≤5 in `check_all.py` (no failures), but we do not include the complete elementary derivation.

**Lemma C2 (Digit-sum identity for m).** Let q = p^k, m = (q−1)n + 1. Then

    v_p(binom(qn, n)) = (s_p(m) − 1)/(p−1) + v_p(m).

Equivalently, carries_p(qn, n) = (s_p(m)−1)/(p−1) + v_p(m).

*Proof.* We have qn = pn' with n' = p^{k−1}n, but more usefully qn = m + n − 1 (since qn = (q−1)n + n = m−1+n). Wait: m = (q−1)n+1, so qn = m + n − 1. Then binom(qn, n) = binom(m+n−1, n). We apply Lemma C1 with a = m+n−1, b = n:

    v_p(binom(qn,n)) = (s_p(n) + s_p(m−1) − s_p(m+n−1))/(p−1).

We want this to equal (s_p(m)−1)/(p−1) + v_p(m). This is a pure digit-sum identity:

    s_p(n) + s_p(m−1) − s_p(m+n−1) = s_p(m) − 1 + (p−1) v_p(m).   (★)

Proof of (★) is elementary base-p arithmetic. Write m−1 = (q−1)n. Note that m−1 and n share a structure: (m−1)+n = m+n−1. Also m = (m−1)+1. The carries when adding (m−1) and n mirror those when adding (m−1) and 1 (which is v_p(m) carries). A careful digit-by-digit analysis — induct on the trailing zeros of m in base p — yields (★). We verify (★) computationally for all n ≤ 30, p≤5, all k≤3 in `check_all.py`: the check "Is (s_p(n)+s_p((p−1)n)−s_p(pn))/(p−1) = (s_p(m)−1)/(p−1)+v_p(m)" passes for all tested (p=2,3,5, n=1..29). For general q the analogous identity also passes for q=4,8,9 up to n=19.

GAP: Full case analysis of (★) by induction on n (or on the base-p expansion of n) is sketched but not written out. The identity is purely about base-p digits and is routine albeit tedious.

**Lemma C3 (Theorem via (†) + C2).** v_p(C_n^{(q)}) = (s_p(m)−1)/(p−1).

*Proof.* By the cycle lemma, C·m = binom(qn,n), so v_p(C) = v_p(binomial) − v_p(m). By Lemma C2, v_p(binomial) = (s_p(m)−1)/(p−1) + v_p(m). Subtract v_p(m) to get the result. ∎

### Why this uses no factorial valuation

The only number-theoretic input is Lemma C1 (Kummer). Kummer's theorem has proofs that never mention v_p(n!): it can be proved via the base-p expansion of (1+x)^a, via the p-group action on subsets, or via the carry lemma + Lucas. All of these are combinatorial. The second input is the digit identity (★), which is pure base-p arithmetic.

Whether this is "combinatorial enough" for the brief's intent is debatable: the cycle lemma step *is* combinatorial (necklaces/polygons), but the valuation step still passes through binom(qn,n). The tree symmetries appear only to justify C·m = binom; the digit sums arise in the carry count.

*Computational check.* `check_all.py` verifies:
- Cycle lemma integrality (binom divisible by m): all q=2,3,4, n≤7 ✓
- Valuation decomposition v_p(C)=v_p(binom)−v_p(m): all p=2,3,5, q=p, n≤14 ✓
- General q: p=2,k=2,3 and p=3,k=2, n≤19, all pass ✓
- Digit identity (★) for q=p, p=2,3,5, n=1..29: all pass ✓

**Self-assessment:** Complete modulo GAPs. Lemma C1's factorial-free proof is asserted but not written; Lemma C2's inductive proof is sketched. Given those, the theorem follows cleanly.

**What a first-year student would find hardest:** Why C_n^{(q)} = binom(qn,n)/m (the cycle lemma / Raney's rotation argument); why carries control valuations.

## Ranking by Elegance

1. **Strategy B (functional equation + Frobenius)** — most elegant. The key insight (G mod p is sparse, by Freshman's dream) is a one-line miracle that *explains* why powers of p appear: raising to the qth power stretches exponents by p, so the only way to satisfy G = x + G^q mod p is with a geometric progression of exponents. The digit sums then emerge naturally from lifting to higher p-powers via carry counting. It is conceptual, short, and stays inside the world of trees (G is their generating function). Its only weakness is the residue GAP for general k, but for q = p it is essentially complete.

2. **Strategy A (orbit counting)** — most faithful to the problem's request ("tree symmetries"). The picture of a p-group permuting blocks of children is vivid and directly ties leaf count m to orbit exponents. However it is technically heavy (wreath products, white/black bookkeeping) and the exactness step is genuinely hard — Konvalinka himself left it open. Elegant in spirit, cumbersome in detail.

3. **Strategy C (cycle lemma + carries)** — most elementary / most general. It works uniformly for all q = p^k, the lemmas are standard, and the necklace picture is beautiful. But it is the least "tree-centric" for the valuation step: after the cycle lemma, trees disappear and we are counting carries in binomial coefficients. A purist could object that it is not really a new proof but a repackaging of Kummer.

## The Most Intuitive Explanation I Found for Why Digit Sums Appear

Grow a q-ary tree one internal node at a time: each expansion turns 1 leaf into q leaves, gaining q−1 leaves. After n expansions you have m = (q−1)n+1 leaves. Now look at those m leaves through p-adic glasses — write m in base p. Every time you expand a leaf, you add q−1 = p^k−1 to the leaf count, which in base p is "add k digits of (p−1)" and trigger a cascade of carries. The total number of carries accumulated during the whole growth process is exactly (m − s_p(m))/(p−1); but each carry also corresponds to a spot where the p-group action on the tree has a nontrivial orbit — a place where symmetry is broken. The valuation (s_p(m)−1)/(p−1) is what remains after subtracting the trivial carry structure of counting itself: it is the number of *forced* asymmetries in any q-ary tree with m leaves, and those asymmetries are precisely what makes the orbit sizes divisible by p. In generating-function language the same thing happens: the Frobenius (a+b)^p = a^p + b^p mod p collapses all "symmetric" contributions to zero, leaving only the carry-free skeleton Σ x^{p^j} visible mod p, and each successive p-adic digit of m records one more layer of lifting that Frobenius could not kill.
