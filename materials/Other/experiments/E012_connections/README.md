# E012 — exact statements behind the motivation pictures

- **Date:** 2026-11-14, by Claude Fable 5.2 (orchestrator). Not human-reviewed.
- **Belongs to:** `notes/2026-11-14_motivation_and_connections.md` and the figures in `talk/figures/`.

## Goal

The motivation part of the talk shows pictures with numbers in them (55 = 1 + 9 + 9 + 9 + 27, class sizes 1, 2, 4, 8, and so on). This experiment checks every such number, so that no picture says more than what was computed.

## Method

`uv run python experiments/E012_connections/run.py` (output in `output.txt`). Plane trees are enumerated explicitly as nested tuples; rotation classes by canonical forms.

| Part | Statement | Result |
|---|---|---|
| A | The 55 plane ternary trees with 4 nodes fall into 5 rotation classes of sizes 1, 9, 9, 9, 27; the named representatives (tert-butyl, isobutyl, the two sec-butyls, n-butyl) lie in different classes; the two sec-butyl classes are mirror images of each other, the others are their own mirror image. Class counts for n = 1..7: 1, 1, 2, 5, 11, 28, 74 up to rotation; 1, 1, 2, 4, 8, 17, 39 up to rotation and reflection. | pass |
| B | For one 4-ary node: orbit sizes of child patterns under all 24 permutations (1, 4, 6, 6, 12, 12, 24) and under the 8 moves generated by the three binary swaps (1, 4, 2, 4, 4, 8, 8; always a power of 2). The 8 moves form a group of order 8. | pass |
| C | The number of binary trees with m leaves and height ≤ H is divisible by 2^(s_2(m)−1), for every m and H ≤ 7; in these ranges the power of 2 is exactly s_2(m) − 1. The same divisibility for 4-ary trees of height ≤ 3. | pass |
| D | v_2 of the number of 256-ary trees with n nodes is s_2(255n + 1) − 1, n ≤ 200. | pass |
| E | v_2(Catalan(n)) = popcount(n + 1) − 1, n < 5000. | pass |
| F | The two trees of the carry-budget figure (7 leaves): 4 carries each; 0 and 3 of them at asymmetric nodes; d = 2 and 5. | pass |
| G | The 132 binary trees with 7 leaves have 11 shapes: 3, 3, 4, 1 shapes with d = 2, 3, 4, 5. | pass |

## Analysis

- Part A is what makes the butyl picture safe: the identification of classes with the named groups is checked on the trees; the chemical names themselves are standard nomenclature (source check in `notes/2026-11-14_motivation_sources.md`).
- Part C: divisibility for bounded height is a consequence of the main proof (rotations preserve the height, and every class has at least 2^t trees). That the power is *exactly* s_2(m) − 1 for bounded height is only an observation here (H ≤ 7), not a claim.
- The figure script `talk/figures/make_figures.py` recomputes the numbers it draws and asserts them, independently of this script.
