Asymmetric nodes: groups not all alike

IN THE PROOF · DEFINITION

“A node is asymmetric if its immediate subtrees (T₁,…,T_p) do not all have the same rotation class. Otherwise it is symmetric. Let d(T) be the number of asymmetric nodes of T.”

And d(T) is the same for every tree in a class (Lemma d-invariant), so d belongs to the molecule.
