A ternary tree is a drawing of an alcohol

IN THE PROOF · DEFINITION

“A p-ary tree is either a leaf or an ordered p-tuple (T₁,…,T_p) of p-ary trees, attached from left to right to a new root.”

Root, 2 nodes, 5 leaves.

IN CHEMISTRY · ETHANOL

Carbon has 4 bonds: one goes up to the root, so 3 point down. Each down-bond holds a carbon (a node) or a hydrogen (a leaf).

orange = OH (root)

gray = carbon (node)

blue = hydrogen (leaf)

Quote: paper/main.tex, the definition of a p-ary tree. With p = 3, alcohols C_nH_(2n+1)OH and plane ternary trees with n nodes are the same shapes, once the order of the three down-bonds is fixed.

Leaves are the hydrogens on carbon: 2n + 1

IN THE PROOF · EQUATION (LEAVES)

“Replacing a leaf of a plane r-ary tree by an internal node with r new leaves increases the leaf count by r − 1 … Hence ℓ(T) = 1 + (r − 1)·#{internal nodes of T}.”

3 → 5 → 7 leaves: each new node (amber) eats one leaf and brings three.

IN CHEMISTRY · THE FORMULA CₙH₂ₙ₊₁OH

With r = 3: n carbons carry 2n + 1 hydrogens (the H of OH is not counted). That is why chemists write alcohols as CₙH₂ₙ₊₁OH.

methanol CH₃OH · 3 H

ethanol C₂H₅OH · 5 H

propanol C₃H₇OH · 7 H

butanol C₄H₉OH · 9 H

So s₃(2n + 1) in our theorem is the digit sum of the number of hydrogens on carbon, written in base 3.

Quote: paper/main.tex, equation (leaves), used with r = q = 3. The m = (q−1)n + 1 in the theorem is the number of leaves, i.e. hydrogens on carbon.

A rotation is a spin about a bond

IN THE PROOF · DEFINITION OF ∼

“rot_r(U) = (U₁₊ᵣ, U₂₊ᵣ, …, U_{p+r}) … Let ∼ be the smallest equivalence relation such that (R1) (U₁,…,U_p) ∼ rot_r(U₁,…,U_p) for every r; (R2) if Tᵢ ∼ Tᵢ′ for each i, then (T₁,…,T_p) ∼ (T₁′,…,T_p′).”

(R1): rotate the children of one node. (R2): do it anywhere inside the tree.

IN CHEMISTRY · FREE ROTATION

Looking down the bond toward the root, a carbon’s three groups sit 120° apart. At room temperature they spin freely, so all three positions are the same molecule.

Spin 120° each time: the cyclic order (orange, teal, purple) never changes.

Quote: paper/main.tex, the definition of rotation equivalence. The chemists’ model with free rotation about every C–C bond and the root corner of the tetrahedron fixed is Robinson, Harary and Balaban (1976), as reported in the guest note guests/andrei-claudecode/notes/2026-11-14_chemistry_deep_dive.md.

A rotation class is one molecule

IN THE PROOF · DEFINITION

“Two trees in one class are called rotation equivalent; [T] denotes the class of T.”

C₂⁽³⁾ = 3 plane trees, and they form one class [T].

IN CHEMISTRY · ONE STEREOISOMER

A chemist writes all three drawings the same way, because the molecule spins between them by itself:

CH₃–CH₂–OH

So plane trees are flat drawings, and rotation classes are the molecules themselves (stereoisomers: left- and right-handed forms count as different).

Our class counts for n = 1…8 are 1, 1, 2, 5, 11, 28, 74, 199: the stereoisomer counts of alcohols (OEIS A000625; Blair and Henze 1932). Checked by script up to 14 carbons.

Class counts as stereoisomer counts: guest experiment guests/andrei-claudecode/experiments/EC01_chemistry_tower, checks A1 to A2, compared with OEIS A000625.

Asymmetric nodes: groups not all alike

IN THE PROOF · DEFINITION

“A node is asymmetric if its immediate subtrees (T₁,…,T_p) do not all have the same rotation class. Otherwise it is symmetric. Let d(T) be the number of asymmetric nodes of T.”

And d(T) is the same for every tree in a class (Lemma d-invariant), so d belongs to the molecule.

Each lopsided carbon triples the drawings

IN THE PROOF · LEMMA (CLASS SIZE)

“For every p-ary tree T, |[T]| = p^d(T).”

At a symmetric node a rotation changes nothing (factor 1). At an asymmetric node it gives p different trees (factor p).

|[T]| = 3ᵈ

IN CHEMISTRY · DRAWINGS PER MOLECULE

tert-butanol: no amber carbon, d = 0, 1 drawing

butan-1-ol: 3 amber CH₂’s, d = 3, 27 drawings

Quote: paper/main.tex, Lemma Class size. Amber = lopsided carbon (an asymmetric node of the proof; not a chemist’s “asymmetric carbon”). tert-butanol is the complete tree K_2.

Spins that change nothing

IN THE PROOF · LEMMA (TUPLE ROTATION)

“Let (B₁,…,B_p) be a tuple in any set. A rotation by r ≠ 0 fixes it if and only if B₁ = ⋯ = B_p.”

A consequence, checked by script (not a lemma of the proof): each node gives its factor 3 either to the class size or to the spins that fix the tree.

class size × fixing spins = 3ⁿ

IN CHEMISTRY · tert-BUTYL: 81 FIXING SPINS

All 4 carbons hold three identical groups, so every spin fixes it: 3 × 3 × 3 × 3 = 81 in our model, class size 1.

81 is the printed symmetry number of the tert-butyl radical with rotating methyls (Gilson and Irikura 2010); none is printed for an alcohol. 81 is also the largest power of 3 dividing 9!.

Quote: paper/main.tex, Lemma tuple-rotation. The product formula is claim C23 (d) of CLAIMS.md, grade computed: a symmetric node contributes 3 to the fixing spins, an asymmetric node 3 to the class size. The source gives 162 for the radical when inversion is included. Only the tert-butyl radical’s 81 is printed in a source; a symmetry number for the alcohol itself is our model’s, so say “in the model”. Gilson–Irikura is reference 11 of references/README.md; the 81 match is guest check F3–F4 (not checked by a chemist).

The fewest lopsided carbons set the power of 3

IN THE PROOF · PROPOSITION (LOWER BOUND)

“t(ℓ(T)) := (s_p(ℓ(T)) − 1)/(p − 1) is an integer. Moreover, d(T) ≥ t(ℓ(T)), with d(T) = 0 exactly when T is complete.”

So every class has size at least 3ᵗ. Classes with d = t are called minimal; the proof shows their number is prime to 3, so v₃ = t exactly.

IN CHEMISTRY · FEWEST LOPSIDED CARBONS

tert-butanol, n = 4: 9 H = 100₃, t = 0. Complete tree, d = 0.

neopentyl alcohol, n = 5: 11 H = 102₃, t = 1. One amber carbon, d = 1.

The number of 3’s in the tree count = the smallest d of any alcohol with n carbons.

Rotations, not swaps: stereoisomers

IN THE PROOF · INTRODUCTION

“In that group-action argument, the branches at each node are permuted by a full symmetric group, orbit sizes are products of multinomial coefficients … Here we instead rotate the p branches at each node …, so that the symmetries form a p-group.”

Full symmetric group S₃ = Konvalinka. Rotations ℤ₃ = ours.

Why 55 is not divisible by 3

IN THE PROOF · THEOREM 1

“If p is prime, k ≥ 1, q = p^k, n ≥ 1, and m = (q − 1)n + 1, then v_p(C_n^(q)) = (s_p(m) − 1)/(p − 1) =: t.”

n = 4, q = 3: m = 9 = 100₃, s₃ = 1, so t = 0. The theorem says 3 ∤ C₄⁽³⁾ = 55.
